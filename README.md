🏡 Airbnb Clone – Full Stack MERN
A full-stack web application inspired by Airbnb, built with the MERN stack (MongoDB, Express, React, Node.js).  
This project allows users to list, browse, and book rental properties with secure authentication and a responsive UI. 

🚀 Features
- 🔐 User authentication & authorization (JWT)
- 🏠 Property listings with image uploads
- 🌐 Live deployment on Render

- Live Demo
